# 日次作業ログ

このファイルは、Claude Codeとのやり取りの中で生じたその日の決定事項・実装/修正内容を記録するファイルです。
お客様との日次定例で使用します。

ガードレール(CLAUDE.md・個人スキル)自体の変更履歴は`.claude/CHANGELOG.md`に記録するため、
このファイルには含めません。

## 運用

- 記入単位: `## YYYY-MM-DD` の見出しの下に、「決定事項」「実装/修正内容」を箇条書きで記載する。
- 保存期間: 3か月。記入日から3か月を超えたエントリは、次に本ファイルへ追記するタイミングで削除する。
